Shadow-Sentinel

View source on GitHub  |  Play on itch.io

About

Implemented a sound detection stealth system, advanced enemy AI and modular systems for customizing enemy logic and animations.

Project Info

  • Engine: Unity
  • Student Assignment
  • Role: Gameplay Dev
  • Team Number: 4

Details

This was my first real game project for a class at Full Sail. The assignment was to build a small stealth prototype — I wanted enemies to feel believable and react to the noises the player makes.

My role

I was the Gameplay Developer: I implemented player movement, the minimap, player and enemy animations, the enemy AI, and the sound detection system. It was a small team project and I picked up many practical Unity skills.

What I worked on

  • Player systems — movement, input handling, and animation blending so the character feels responsive.
  • Minimap — a simple UI minimap to help with navigation and awareness in tight levels.
  • Sound detection — footsteps and actions generate configurable noise that can alert nearby enemies.
  • Enemy AI — patrols, sight cones, investigation behavior and alert/chase states driven by a basic FSM.
  • Enemy animations — transitions and state-driven animations for patrol, alert, and chase.

Technical notes

  • I used a Finite State Machine for enemy states and added hooks so behavior could be changed without rewriting core logic.
  • Detection uses a combination of noise radii and line‑of‑sight checks — this helped balance stealth and fairness.
  • Animator controllers and blend trees were used to keep player/enemy motion smooth.
  • To keep performance reasonable I used lightweight update loops and pooled short‑lived objects (like sound markers/effects).

Challenges & what I learned

Tuning detection ranges and timing was harder than I expected — small numbers made the game frustrating, large numbers made it too easy. I learned to use debug gizmos and logs to visualize AI perception. Working in a small team taught me practical Git workflows and how to divide features. Overall I learned a lot about Unity's animation system, scripting gameplay behavior in C#, and iterating quickly on playfeel.
