RasterSurface 3D Renderer

Software Rasterization Pipeline — Built from First Principles

View Source on GitHub

About

A custom software renderer built from scratch using a RasterSurface. Implements the full 3D pipeline: vertex transforms, triangle rasterization, depth buffering, barycentric interpolation, and per-pixel Phong lighting.

Project Info

  • LanguageC++
  • TypeStudent Assignment
  • Team SizeSolo

Overview

This assignment taught how to render and light a 3D object from first principles using a RasterSurface — no graphics API, no shortcuts. Every stage of the pipeline was implemented manually in C++.

What I Implemented

Vertex Transforms

Model, view, and projection matrices applied per-vertex to transform geometry from object space through to clip space and onto the screen.

Triangle Assembly & Rasterization

Assembled transformed vertices into triangles and rasterized them pixel by pixel, computing coverage and interpolating attributes across each triangle's surface.

Depth Buffering

A per-pixel depth buffer to correctly resolve occlusion — fragments failing the depth test are discarded, ensuring surfaces render in the right order without sorting geometry.

Barycentric Interpolation

Per-pixel attributes — positions, normals, and UVs — interpolated across triangle faces using barycentric coordinates, feeding accurate data into the lighting and texture stages.

Per-Pixel Phong Lighting

A full ambient + diffuse + specular lighting model evaluated per pixel using interpolated world-space normals and surface positions for smooth, accurate shading.

Camera Transforms & Texture Lookup

Camera view matrix applied to position the scene, paired with simple UV-based texture sampling and final color clamping before writing to the RasterSurface output.

What I Learned

Building the full rasterization pipeline by hand gave me a deep understanding of how depth testing, barycentric interpolation, and per-pixel shading work together to produce a correctly lit 3D image. Seeing how each stage feeds the next — from vertex transform all the way to a final pixel color — made the mechanics of real-time graphics engines much more concrete.
